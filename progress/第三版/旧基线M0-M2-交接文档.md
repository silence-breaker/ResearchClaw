## 3. 关键修复记录

### M2-01：`contract_draft` 阻塞后无法 recover

**问题**：`contract_draft` 进入 `blocked` 后，`state.block.retreat_to` 为 `null`，`POST /recover` 报 "No retreat target is available"。

**修复文件**：

- `researchclaw/engine/orchestrator.js`
  - `retreatTargets` 增加 `contract_draft: "contract_draft"`
  - `_failContractRun` 使用 `retreatTargets.contract_draft` 代替硬编码 `null`
  - `recover()` 对 `contract_draft` 目标特殊处理：设置 `pendingRun`、返回 `needs_draft: true`、显示 `phase_running`
- `researchclaw/server.js`
  - `/recover` 端点在 `result.needs_draft` 时后台调度 `executeContractRun`
- 新增回归测试
  - `researchclaw/tests/engine.test.js`：2 个测试
  - `researchclaw/tests/server.test.js`：1 个 HTTP 层端到端测试

### M2-LOW-01：死代码 `adapterError`

**问题**：`adapters/types.js` 中 `adapterError` 硬编码 `adapter: "mock"` 且未被引用。

**修复**：删除该函数，保留 `modelAdapterNames`。

## 4. 架构红线（必须继续遵守）

| 红线 | 含义 | 检查点 |
|------|------|--------|
| Engine 是唯一科研状态源 | 只有 `ResearchOrchestrator` 能写 research state | `npm test` |
| 两通道物理分离 | 结论只来自 artifact → gate；transcript/raw_log/cli_chunk 只代表过程 | 面板右栏标「过程」 |
| Artifact + gate 才推进 phase | 每个 phase transition 必须有 gate 结果 | gate 测试全覆盖 |
| Consult 是旁路 | consult 不推进 research state，不进 claim evidence | M2 时仍 disabled；2026-07-09 复核：Claude consult 已实现，仍保持旁路语义 |
| 默认 Haiku，绝不默认 Opus | 真实 CLI 默认 `claude-haiku-4-5` | `server.js` 启动检查 |
| Mock 永远是回放底座 | CI / `demo:fixture` 全 mock 零额度 | 不配置时 `RESEARCHCLAW_ENABLE_CLAUDE` 为 falsy |
| API key 不泄露 | key 不进日志/SSE/artifact/错误信息/前端状态 | provider status 脱敏 |
| 降级要诚实 | 回退 mock 后产物 `adapter:"mock"`，面板如实显示 | 来源徽章 + 降级 banner |
